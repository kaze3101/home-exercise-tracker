## 1. テスト方針

- **入力値チェック**は、画面側（`logic.py`）とデータベース側（`CHECK`、`UNIQUE`、外部キー）の二重で守る設計とし、それぞれを個別に確認する。
- 入力値の境界（NRSの0と10、日付の当日と翌日など）を重点的に確認する。
- 自動テスト（pytest）で確認できる項目と、画面を操作して確認する項目（手動テスト）に分けて実施する。

## 3. 自動テスト（pytest）

実行方法：プロジェクトのフォルダで `.venv/bin/python -m pytest -v` を実行する。
